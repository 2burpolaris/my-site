# 우리 집 장보기

따뜻한 종이 메모 느낌의 장보기 체크리스트예요. 품목이 종류별 칸(채소·과일, 고기·생선, 유제품·계란, 곡물·가공식품, 생활용품)에 나뉘어 있어요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `shopping-list.html` | 내 컴퓨터 혼자 쓰는 버전이에요. 더블클릭하면 브라우저에서 열려요. 체크한 내용은 그 브라우저 안(localStorage)에만 저장돼요. |
| `shared-shopping-list.html` | 가족이 함께 쓰는 버전의 소스예요. claude.ai 아티팩트로 올라가 있고, 아티팩트 공용 저장소(`db`)에 목록을 저장해요. 이 파일만 따로 열면 목록이 보이지 않아요. |

공유 버전 주소: https://claude.ai/artifact/GkYsz318ix1wReWeQWgR2Q

## 기능

- 항목 체크하기와 체크 풀기
- 새 항목 추가하기 (이름과 종류를 골라요)
- 항목 삭제하기
- 산 항목 숨기기/보이기
- 체크 모두 풀기 (항목은 그대로 남아요)
- 남은 개수 표시

손글씨 글꼴(Gaegu)만 Google Fonts에서 받아 와요. 인터넷이 안 되면 보통 글꼴로 보여요.
